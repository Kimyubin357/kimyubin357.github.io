# 제조 전력 예측 공개 근거

분석 기간은 2026년 10월 2~8일이며, 2021년 제공 데이터를 사용했습니다. 공개 파일의 수치·해석 범위는 2026년 10월 15일에 저장 결과와 대조했습니다.

## 역할과 접근의 출처

김유빈은 변수·근무 리듬·반복 패턴의 질문과 가설 검증, 울산 공식 기상 대조와 시차 조사, 실험 조건·팀 결과 통합·AI 교차검토를 주도했습니다. 권동현의 유사일·잔차 및 최근 흐름 접근을 참고해 자체 조건에서 재실험했고, 고도현의 독립 분석·보고서와 비교했습니다. 코드·학습·집계·그림은 Codex·Claude Code 지원으로 구현했습니다. 모델 성능은 공동 실험 결과입니다.

- contributions.json: 개인 판단, 팀원 접근, AI 구현 범위.
- metrics.json: 모델·경보·데이터 품질·검증 기록과 모델 선택 범위.
- model_comparison.csv: 동일 9월 평가 행의 Q1·Q2·Q3·LSTM 비교.
- analysis_summary.json: 공식 기상 대조·리듬·반복 프로파일 집계.
- make_model_comparison.py: `model_comparison.csv`의 `mae`·`high_mae`로 사이트 그림 `assets/power-forecast/06_model_comparison.png`(2560×950)를 다시 그리는 스크립트(2026-10-17). 페이지 용어에 맞춰 Q1·Q2·Q3를 기준·제출·피크 특화 모델로 표기한다. 실행: `python make_model_comparison.py model_comparison.csv 06_model_comparison.png <SUIT-Regular/Bold.ttf 폴더>` (SUIT 가변 글꼴을 450·700 정적 TTF로 변환해 사용).

## 수치의 해석

Q1은 HGB 직접·잔차 혼합, Q2는 LightGBM 재가동 입력과 직접·유사일 잔차 혼합, Q3는 고전력 가중 잔차입니다. Q2·LSTM 비교 후 Q3를 실험했고, 이미 탐색한 9월 회고의 전체 오차와 큰 오차 부담을 고려해 Q2를 제출 대표로 선택했습니다. 새 기간에서의 검증이 필요합니다.

Q2는 기존 Q1 대비 개발 교체 보호 조건을 통과하지 못했습니다. Q3는 신규 프로파일 고전력 오차를 14.22% 줄이고 개발 보호 조건을 통과한 별도 목표의 후보입니다. 최종 Q2 선택에는 9월 회고 결과가 포함됐습니다. 9월은 독립 시험이 아닙니다.

5,376행은 1,344개 실제 15분 구간에 대한 네 예측 거리의 결과입니다. 전력값 예측과 ExtraTrees 경보는 별도입니다. 56/56 사건 탐지는 189개 위험 칸을 모두 맞혔다는 뜻이 아닙니다. 오경보 표시 시간은 작업자의 실제 검토 시간이 아닙니다.

## 기상과 누출 수정 범위

5월 22일 이후 원자료 t시 기상이 울산 ASOS 152의 공식 t+1시 관측과 대응했습니다. 원자료 lag1은 이전 1시간 예측 발행 시각 이후의 관측을 포함했습니다. 수정 범위는 이전 1시간 최대값 모델의 원자료 기상 묶음 제거입니다. 모든 과거 모델을 수정했다는 의미는 아닙니다.

15분 모델은 공식 관측·가용 시각으로 연결했습니다. 관측 후 1시간부터 사용 가능하다는 실험 가정이며 실제 API 공개 지연은 미검증입니다. 울산 관측 일치는 공장 위치나 전력 구간의 실제 시각을 확정하지 않습니다.

## 검증과 후속 과제

저장된 제출 패키지 검증은 99개 테스트, 전력 5,376행·경보 1,343행 재예측을 포함하며 최대 차이는 약 2.84×10⁻¹⁴입니다. 이번 웹페이지 수정은 저장 집계·선택 결과를 대조했으며 모델을 재학습하거나 테스트를 다시 실행하지 않았습니다.

원자료 시간·단위 확인, 실시간 기상 도착 검증, 새 기간의 성능·경보 부담 및 실제 설비·일정 제약에 따른 조치 효과가 후속 과제입니다. 소속·서명·설문 화면·API 인증키·편집 메모는 공개 근거에 포함하지 않습니다.
