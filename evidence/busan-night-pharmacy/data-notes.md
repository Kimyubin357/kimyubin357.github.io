# 부산 심야약국 사례: 출처와 해석 범위

자료 기준은 2026-10-13이며 10-14 위치 보정을 반영했습니다. 이후 API 조회 검사는 별도 실행 기록이며, 분석 결과를 최신 값으로 자동 갱신한 것이 아닙니다.

## 자료

- [부산 약국 API](https://www.data.go.kr/data/15163576/openapi.do): 약국 ID·주소·좌표·요일별 운영시간. 1,701건 중 부산 1,696곳을 분석했습니다.
- [NMC 전국 약국 API](https://www.data.go.kr/data/15000576/openapi.do): 부산 1,714건, 시설 대조와 시간표 보완. 두 원천을 합친 시민 지도는 1,716곳입니다.
- [공공심야약국 명단](https://www.data.go.kr/data/15127987/fileData.do): 2026-08-10 명단의 19곳과 정책 운영시간.
- 부산 빅데이터웨이브 PD_LP00003: 2026-07 행정동별 22·23·00시 생활인구.
- SGIS 2024년 100m 인구격자·2025-06-30 행정동 경계: 동 수요를 거주인구 비중으로 배분합니다.
- OpenStreetMap / Geofabrik: 2026-10-12 도로망. 기본 4km/h, 도로 구간 연결과 최단경로 계산.
- 부산 도로명주소: 구·도로명·건물번호 대조와 위치 보정.
- 심평원 2026-06 분기 파일: 초기 비교 검토. 심평원만으로 보완한 값은 최종 주모형에서 제외했습니다.

## 시간표 처리 순서

원본 보존 → 초기 지정약국 19곳 월요일 시작 추정 → 심평원 일부 보완 검토 → NMC로 미상·추정 시간표 교체 → 부산/NMC 충돌은 NMC 우선 → 남은 결측의 조건부 가정 또는 미상 유지. 단계별 보완 수는 중복될 수 있어 합산하지 않습니다.

분석 대상 1,696곳의 월요일은 NMC 1,679곳·화~금 동일 시간 가정 3곳·미상 14곳입니다. 99%는 이 시간표의 보완 비율이며 정확도가 아닙니다. 자동 가정과 본인이 검색·교차 대조한 작업은 구분합니다.

토·일이 두 원천 모두 공란이고 화~금이 완비된 일반약국은 주말 휴무를, 일요일만 공란이고 화~토가 완비된 경우는 일요일 휴무를 가정합니다. 공공심야약국은 정책시간을 별도 가정으로 구분합니다. 그 밖의 부족한 근거는 미상으로 남깁니다.

## 분석과 수치

후보 한 곳이 매일 22–익일 01시에 운영한다고 가정하고 기존 공급으로 접근하지 못하던 잠재수요 중 새로 접근 가능한 양을 7요일×3개 출발 시각으로 계산해 평균합니다. 수영우리약국의 15분 기본 조건 평균은 하한 42,953명·상한 43,817명이며 실제 이용자 수가 아닙니다. 월요일 23시 한 조건의 43,143–44,009명과 구분합니다.

하한에도 명시한 시간표 보완·휴무 가정이 포함됩니다. 하한–상한과 민감도 순위는 통계적 신뢰구간, 현장 영업·도보 검증, 실제 서비스 효과가 아닙니다. 참여 의향과 지정 자격을 확인한 추천 결정도 아닙니다.

## 역할과 프로젝트

개인으로 2026 BIG DATA 활용대회에 지원했고 본선에는 진출하지 못했습니다. 접수 마감은 9월 18일입니다. 이후 재현성·분석 설명·화면을 보완했습니다.

직접 담당한 범위는 외부 데이터 선정, 운영시간 검색·교차 대조와 전처리, 보행거리 기반 후보 분석 아이디어입니다. 분석·파이프라인·대시보드·검사 코드는 AI의 도움을 받아 구현했습니다. 임의의 기여율이나 모델 개발·현장 검증 실적을 기재하지 않습니다.

## 이 폴더의 근거

- `opening-hours.json`: 당시 처리 순서와 새 API를 이용한 실제 코드 실행 요약.
- `validation.json`: 후보 점수 10,062개 재집계·경로 계산 일치 검사.
- `sensitivity.json`: API·15분 조건의 가정별 기본 후보 순위와 선두 점수.
- `loading.json`: 첫 화면 필수 파일 합계 8.98MB→1.10MB의 근거. 실제 시간 개선율이 아닙니다.

포트폴리오 표시를 위한 필요한 요약과 출처 해시만 포함합니다. API 인증키·서비스 설정·원천 대용량 자료는 포함하지 않습니다. 이 정적 포트폴리오를 실행하는 데 원래 분석 폴더나 API 키는 필요하지 않습니다.

## 판단 사례와 공개 코드

미소약국(C1200758)·우리약국(C1200498)의 월요일은 부산 원본 시작 공란 → 초기 심평원 보완 → NMC 값 교체 이력입니다. `decision-cases.json`에 값과 원천 해시를 보존했습니다. 개별 웹 검색 URL·조회일·수동 확인 총수는 보관 자료로 입증되지 않아 임의로 기재하지 않습니다. `troubleshooting.json`은 좌표·시설 선택·갱신 실패 처리 근거입니다.

[공개 GitHub 저장소](https://github.com/Kimyubin357/busan-night-pharmacy-map)에서 분석 구현과 재현 순서를 확인할 수 있습니다. 공간 접근성은 출발 시각에 보행시간을 더한 도착 순간으로 판정하며 전날부터 이어지는 영업과 종료 정각 제외를 반영합니다.
