01 울산 관측과 대조해 기상의 시차를 찾았습니다.

본인 주도 · 자료 대조와 검증 설계 / 계산·시각화는 AI 협업

기상 결측 보완을 제안한 뒤 온습도와 전력의 관계까지 탐색했습니다. 비슷한 기상 기록으로 관측소 후보를 찾자는 아이디어를 제시하고, 공식 API 자료를 확보해 울산 ASOS 152의 기온·습도·풍속과 대조했습니다.

  1. 발견5월 22일부터 원자료 기상이 공식 관측보다 한 시간 앞선 행에 붙어 있었습니다. 지속되는 시차와 산발적 불일치를 구분했습니다.
  2. 판단과거 기록처럼 보이는 행에 예측 당시 알 수 없던 기상값이 들어 있었습니다. 행 번호 대신 공식 관측 시각으로 입력의 가용성을 다시 확인했습니다.
  3. 적용공식 시각 대조 결과와 입력 코드를 근거로 Claude Code의 누출 지적을 Codex와 교차검토했습니다. 이전 1시간 최대값 모델의 원자료 기상 묶음을 제외해 재실행했고, 15분 모델은 공식 관측·가용 시각으로 연결했습니다.

15분 실험은 공식 관측 후 1시간부터 사용 가능하다고 가정했습니다. 실제 API 공개 지연을 검증한 값은 아닙니다. 풍속 결측 3행은 동시 비교에서 제외했고 불일치 10행을 남겼습니다. 과거 모델의 수정 범위는 1시간 최대값 모델이며 공장 위치·전력 구간의 실제 시각 정의는 미확인입니다.

02 작업 리듬과 데이터 반복을 나눠 검증했습니다.

본인 질문·가설 검증 / 정밀 집계·그림은 AI 협업

“매주 비슷한 전력 흐름은 사람의 작업 리듬일까, 데이터를 반복한 것일까?”라는 질문에서 시작했습니다. 근무 리듬과 완전히 같은 수치의 반복을 나누어 확인했습니다.

① 작업 리듬을 수치로 확인

② 완전히 같은 하루를 발견하고 채점 기준 보완

  1. 발견AI 집계로 완전한 255일 중 140개 고유 전력 패턴을 확인했습니다. 96개 전력값이 모두 같은 날짜 쌍은 302개였고, 그중 178쌍은 생산량이 달랐습니다.
  2. 판단6월 30일 중 28일이 이전 학습 기간에 등장한 패턴이었습니다. 전체 오차만 보면 처음 보는 날의 성능을 과대평가할 수 있다는 팀·AI의 검토를 수용했습니다.
  3. 적용전체 오차와 함께 학습에 없던 프로파일의 MAE·고전력 MAE를 비교했습니다. 반복 여부는 사후 채점용이며 미래 예측 입력에는 넣지 않았습니다.

③ 기상 시차를 전력에도 적용할지 교차검증

기상 시차가 전력·생산에도 적용되는지 확인하기 위해 5월 22일 앞뒤 28일의 월~금 각 20일을 비교했습니다.

기상의 시차를 전력·생산 열에 일괄 적용하지 않았습니다.

전후 모두 기록된 12시 저점과 13시 회복이 유지됐고 저녁 리듬도 같았습니다. 모든 열을 1시간 이동할 근거는 얻지 못했습니다. 실제 전력 구간의 시작·완료 시각을 확정한 결과는 아닙니다.

저녁 패턴으로 같은 판단을 추가 확인

17시 하락·18시 반등과 19→20시 생산 급감이 같은 기록 시간에 유지됐습니다. 두 비교 모두 공휴일을 별도 제외하지 않았으며 선은 중앙값, 음영은 사분위 범위입니다.

03 실험을 비교하고 제출 대표 Q2를 선택했습니다.

본인: 평가 기준·선택 판단 / 팀원: 유사일·잔차 접근 / AI: 구현·학습·집계

저는 학습에 없던 패턴과 고전력 오차를 함께 평가하고, 경보의 지속시간·발생 횟수를 모두 검토하도록 기준을 정리했습니다. 권동현 님의 유사일·잔차 접근은 발행 당시 관측 가능한 정보만 쓰는 조건으로 다시 비교했습니다.

  1. 01 · 기준Q1유사일 + 잔차 기준선
  2. 02 · 확장 비교Q2 · LSTM입력·모델·혼합 비교
  3. 03 · 고전력 개선Q3가중 잔차 후보 통과
  4. 04 · 대표 선택제출 대표 Q29월 회고를 포함한 판단

평가 순서 5~7월 개발 → 1~7월 최종 학습 → 8월 경보 보정 → 9월 회고

  1. 01

    Q1 · 비교 기준

    기준 모델로 유지

    문제
    팀원의 접근을 우리 발행 시점 조건에서 검증할 기준이 필요했습니다.
    시도
    직접 예측과 유사일·잔차 예측을 50:50으로 혼합했습니다.
    검증
    신규 프로파일 개발 MAE 6.632.
    판단
    관측 완료 정보만 쓰는 HGB 혼합을 비교 기준으로 유지했습니다.
  2. 02

    Q2·LSTM · 확장 비교

    Q2 교체 조건 미충족 · LSTM 미채택

    문제
    아침·점심 후 큰 오차를 줄일 후보가 필요했습니다.
    시도
    재가동 정보·LightGBM 혼합과 LSTM을 비교했습니다.
    검증
    Q2 신규 프로파일 MAE 0.12% 개선, 고전력 MAE 14.83% 악화.
    판단
    Q2는 교체 조건을 충족하지 못했고, LSTM도 신규 프로파일 개발 오차가 더 컸습니다.
  3. 03

    Q3 · 고전력 개선

    고전력 후보 보호 조건 통과

    문제
    Q2의 고전력 오차는 개선되지 않았습니다.
    시도
    고전력 표본의 학습 가중치를 2배로 둔 잔차 모델을 비교했습니다.
    검증
    Q1 대비 신규 프로파일 고전력 MAE 14.22% 감소.
    판단
    개발 전체 MAE는 2.26% 증가했지만 전체·신규 프로파일 MAE의 5% 악화 제한을 통과했습니다.
  4. 04

    제출 대표 모델: Q2

    9월 회고까지 고려한 선택

    문제
    전체 오차는 Q2, 고전력 오차는 Q3가 더 낮았습니다.
    비교
    전체 정확도와 큰 오차 발생 건수를 함께 봤습니다.
    검증
    9월 Q2/Q3 MAE 5.988 / 6.622, 오차 50 초과 13 / 21건.
    판단
    전체·큰 오차 부담을 고려해 Q2를 제출 대표로 정하고 Q3 결과도 남겼습니다.

9월 고전력 기준은 1~7월 학습값 상위 10%인 169 이상입니다. 개발에서는 각 월 이전 학습분포의 상위 10%를 사용했습니다. 실제 1,344개 구간 × 4개 예측 거리 = 5,376행을 동일하게 비교했습니다. 전력 단위는 원자료 수치입니다.

개발 조건 미충족 → 회고 선택 → 새 기간 검증 필요. Q2는 Q1 대비 사전 개발 교체 조건을 충족하지 못했습니다. 이미 탐색한 9월의 전체·큰 오차 부담을 보고 제출 대표로 선택했습니다. 독립 시험이 아니므로 새 기간의 검증이 필요합니다.

오차 50 초과는 원자료 수치로 정한 사후 설명 기준입니다.

개발 수치·모델 설정·예측 시간 가정

개발 지표: Q1 → Q2의 신규 프로파일 MAE는 6.632 → 6.624, 신규 프로파일 고전력 MAE는 11.812 → 13.563입니다. LSTM 단독 후보의 신규 프로파일 MAE는 8.120이며 LSTM과 트리 예측을 섞은 후보도 미채택했습니다.

사전 교체 기준: 신규 프로파일 MAE가 1% 이상 개선되고, 전체 MAE와 신규 프로파일 고전력 MAE가 각각 5% 넘게 악화되지 않아야 했습니다.

Q3 비교 기준은 Q1입니다. 신규 프로파일 고전력 MAE는 11.812 → 10.132, 개발 전체 MAE는 6.488 → 6.635입니다. 신규 프로파일과 전체 개발 MAE는 서로 다른 집계입니다.

본인 판단: 신규 프로파일·고전력 평가를 함께 보고 전체 오차와 경보 부담도 보호하도록 비교 범위를 정리했습니다. 팀원 참고: 권동현의 유사일·잔차와 최근 흐름 후보. AI 구현: 트리·LSTM·가중 잔차 학습, 누출 검사와 저장 예측 재현.

Random Forest·ExtraTrees·HGB·LightGBM·LSTM과 입력 묶음·고정 혼합을 비교했습니다. 변화량을 입력하는 실험과 변화량 자체를 학습하는 목표는 구분했고, 최종 전력 방식은 직접·유사일 잔차 혼합입니다. 팀원의 탐색 설정을 그대로 복사한 것은 아닙니다.

원자료 네 전력 열을 15분 시간축으로 펼쳐 발행 후 15·30·45·60분에 끝나는 네 칸을 예측하고, 묶인 구간의 평균·최대를 계산했습니다. h시 행의 네 값이 h:15·h:30·h:45·h+1:00에 관측 완료된다는 가정이며, 각 칸 시작까지는 0·15·30·45분입니다.

유사일은 발행 당시 96칸이 관측 완료된 최근 42일 중 최대 3일에서 골랐습니다. 미래 목표값·당일 최종 생산량은 사용하지 않았습니다.

04 큰 실패와 오경보 부담까지 검토했습니다.

“피크를 놓치지 않되 너무 예민하게 반응하지 않게”라는 기준으로 검토했습니다. 전력값 예측과 별도로 기상 없는 ExtraTrees 경보를 평가했고, 8월에서 임계값을 보정한 뒤 9월에는 고정했습니다.

9월 1,343개 경보 평가 칸 · 14달력일 · 대상 칸 시작 15분 전 경보. 위험 기준 169는 학습 상위 10%이며 계약전력 한도가 아닙니다.

짧아진 경보가 더 자주 울리는 문제를 발견했습니다.

시간을 줄이는 후보는 8월 오경보 칸을 247 → 222개로 줄였지만 완전히 헛된 경보 발생은 11 → 19회로 늘렸습니다. 9월에도 227.1 → 190.7분/일로 줄어든 대신 헛된 경보는 10 → 14회로 늘었습니다.
