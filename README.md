# 김유빈 개인 포트폴리오

프로젝트를 계속 추가할 수 있는 정적 포트폴리오 사이트. 기존 Dash·FastAPI·Firebase 실행과 독립적이다.

현재 버전은 **0.4.2 (2026-10-17)**이다. BatteryFlow AI·부산 심야약국·제조 전력 예측을 대표 프로젝트로 소개한다. 포트폴리오 공개 주소는 https://kimyubin357.github.io/ 이며, 연결된 대시보드와 별도의 GitHub Pages 사이트다.

버전의 기준은 `VERSION`이다. 릴리스 시 이 파일, HTML의 CSS·JS `?v=` 값, 이 문서와 `design/SPEC.md`의 현재 버전을 함께 갱신한다. `design/QA.md`는 버전별 검증 이력을 보존한다. 구현 기준은 [SPEC](design/SPEC.md), 검증 결과는 [QA](design/QA.md), 수치 출처는 [근거 자료 안내](evidence/README.md)에 정리했다.

## 실행

Windows에서 이 폴더의 `start.cmd`를 더블 클릭한다. Python 3이 있으면 별도 패키지 설치 없이 http://127.0.0.1:8765 에서 열리고, 창에서 Ctrl+C로 종료한다.

직접 실행: `python serve.py`. 포트 충돌 시 `python serve.py --port 8766`.

`index.html`을 직접 열어도 글·이미지·인터뷰 클립을 볼 수 있다. 인터넷은 GitHub·라이브 서비스·YouTube 원본 링크에만 필요하다.

## 구성과 수정 위치

- `projects.js`: **프로젝트 목록.** 항목을 추가하면 메인에 자동 표시된다. `featured: true` + `order`인 항목(최대 3개)은 상단 "대표 프로젝트"에 큰 카드로, 대표가 아닌 프로젝트가 생기면 "전체 프로젝트" 그리드(분야 필터 포함)가 자동으로 나타난다.
- `project-template.html`: 새 프로젝트 상세 페이지 템플릿. 복사 후 TODO를 채우고 `projects.js`의 `link`로 연결한다.
- `index.html`: 히어로·SBS 인터뷰·대표 프로젝트·소개/기술·학력/자격증·연락처. 학력은 부트캠프·충북대(편입·졸업)·군산대(수료)·삼일상업고(졸업) 순의 가로 타임라인이며 로고는 `assets/logo-ls.png`, `logo-cbnu.png`, `logo-kunsan.png`, `logo-samil.png`(2026-10-13 사용자 제공)이다. 자격증은 상장 형태 카드(정보처리기사·SQLD·컴퓨터활용능력 1급·리눅스마스터 2급, 취득일은 사용자 제공 자격증 PDF의 합격일과 이력서)이며, 학점·주소·연락처는 넣지 않고, 자격증 원본 파일(자격번호·생년월일 포함)은 사이트에 넣지 않는다.
- `batteryflow.html`: BatteryFlow 상세 사례.
- `busan-night-pharmacy.html`: 부산 심야약국 상세 사례. 전후 지도 전환은 `busan-night-pharmacy.js`, 페이지 전용 스타일은 `busan-night-pharmacy.css`.
- `assets/busan-night-pharmacy/`, `evidence/busan-night-pharmacy/`: 실제 캡처 5장과 독립적인 공개용 수치 근거.
- `styles.css`: 공통 반응형 디자인과 스크롤 애니메이션.
- `site.js`: 프로젝트 렌더링, 스크롤 등장·패럴랙스·영상 확대·진행바, 인터뷰 플레이어.
- `assets/`: 사이트 이미지·로컬 폰트. 프로필 사진은 `portrait-480.jpg`/`portrait-960.jpg`를 사용하고 원본 `portrait.png`는 보존.
- `evidence/`: 9가지 방법 전체 비교 CSV, 신뢰구간·순위 JSON, GitHub 원본 대조 결과와 출처 안내.
- `design/`: 현재 구현 기준·검증 기록 및 초기 시안. `SPEC-2026-10-07.md`, `QA-2026-10-07.md`, concept/render 이미지는 과거 기록이다.

대표 프로젝트 영역에는 기본 HTML 상세 링크가 있다. JavaScript 비활성화, `site.js`·`projects.js` 로드 실패, 대표 카드 생성 오류 때도 세 프로젝트 상세 페이지에 접근할 수 있다. 대표 데이터가 있고 카드 생성에 성공했을 때만 이 링크를 카드로 교체한다.

## 인터뷰 영상 동작

2026-10-17부터 YouTube 임베드(광고 노출) 대신 잘라낸 로컬 클립을 재생한다. `assets/interview/sbs-interview.mp4`는 SBS 8뉴스 원본(YouTube RI5JTzQbqe4)의 00:35–00:59 구간 24초(H.264 1280×720, 약 2.6MB, faststart)이고, `sbs-interview-poster.jpg`는 같은 클립 19.8초 지점의 정지 화면이다. 사용자가 제공한 전체 방송 파일 `SBS_8_news.mp4`는 `.gitignore`로 저장소에서 제외한다.

영상 구역이 화면에 45% 이상 보이면 음소거 자동 재생·반복하고, 벗어나면 일시정지한다. "소리 켜고 처음부터 보기"나 재생 버튼을 누르면 소리와 컨트롤을 켜고 처음부터 한 번 재생한 뒤 첫 화면으로 돌아간다. 소리가 켜지면 버튼은 회색의 "소리 끄기"로 바뀌며, 이후 "소리 끄기" / "소리 켜기"는 재생 위치를 유지한다. 영상 자체의 음소거·볼륨 조절에도 버튼이 동기화된다. `prefers-reduced-motion` 사용자는 클릭 재생만 한다. 영상 파일을 불러오지 못하면 YouTube 원본 링크로 전환한다. 영상 아래에 "출처: SBS 8뉴스"와 원본 링크를 표시한다. SBS가 삭제를 요청하면 클립을 지우고 원본 링크만 남긴다.

## 부산 심야약국 추가 · 2026-10-14

사용자가 확정한 포트폴리오 원고에서 본인 역할·AI 구현 지원, 월요일 NMC 보완 1,679곳·가정 3곳·미상 14곳, 후보 순위 민감도와 기준일 데모의 한계를 반영했다. 카드에서 상세 페이지, 지도 전후 전환, 모바일 약국 찾기 캡처와 근거 파일로 연결한다. 원본 분석 작업 폴더를 참조하지 않으며 API 키나 대형 원천 데이터는 포함하지 않는다.

배포 시 `busan-night-pharmacy.html`·전용 CSS/JS와 추가 assets/evidence도 포함한다. 이번 요청은 로컬 사이트 반영으로, GitHub 게시나 사이트 배포를 실행한 의미가 아니다.

## v0.3.1 전력 페이지 기여·가독성 보완

기여 원고를 대화·수치와 대조해 실제 기간10/2–10/8과 질문→검증→적용의 흐름을 반영했다. 역할 세 줄과 상단 요약3개, 모바일에서도 표 밖의 전체/고전력 MAE·개발 미충족·경보 부담을 함께 표시한다. 기상 그림은 대응 시차, 점심 그림은 전력만으로 설명을 바로잡았다. 권동현은 참고후재실험, 고도현은 분석·보고서 비교로 구분하고 AI구현과 본인판단을 분리했다. 저녁·입력상세는 접힌 추가 근거로 이동했다. 기존SUIT·색상·헤더·카드 스타일을 유지한다.

## v0.3.2 전력 분석의 판단·트러블 슈팅 · 2026-10-15

Q1 → Q2·LSTM 비교 → Q3 실험 → 최종 Q2 선택을 네 단계 경로와 문제·시도·검증·선택 이유로 표시한다. Q3의 개발 고전력 개선·보호 조건 통과와 Q2의 기존 Q1 교체 조건 미충족을 구분하며 대표 선택의 9월 회고 맥락을 공개한다. 개인 판단·팀원 접근·Codex/Claude Code 구현을 분리한다.

반복 프로파일·근무 리듬 그림을 열린 본문에 배치하고 점심·저녁 교차검증에서 전력 열을 일괄 이동하지 않은 판단을 설명한다. 이전 1시간 최대값 기상 누출 수정 범위를 명시한다. 실패·경보는 하나의 절로 묶고 성능과 부담은 모바일 HTML 수치로 함께 표시한다. 메인 카드 라벨을 문제/내 역할/핵심 판단으로 통일한다.

공개 기여 JSON의 편집 메모와 내부 저자 확인 필드를 제거하고 수치·검증 범위는 보존한다. 편집 근거는 웹 루트 밖의 분석 작업 공간에 둔다. 기존 모델·학습 데이터·제출 문서는 수정하지 않는다. 디자인·글꼴·색상은 기존 사례 형식을 유지한다.

## v0.3.3 전력 사례의 판단·실험 설명 압축 · 2026-10-15

스타일과 9개 그림의 위치·캡션·원본 링크는 유지한다. 기상 누출은 예측 당시 알 수 없던 값이 입력됐다는 영향부터 설명한다. 개인 기여는 시간 기준 검증·신규 프로파일 평가·경보 지속시간과 발생 횟수의 동시 검토를 앞세운다.

## v0.4.2 BatteryFlow 라이브 서비스 중간 로딩 페이지 · 2026-10-17

BatteryFlow 상세의 "라이브 서비스 열기"는 Cloud Run 주소 대신 `batteryflow-live.html`을 새 탭으로 연다. 이 페이지가 서비스에 요청을 보내 서버(콜드 스타트)를 깨우고, 응답이 오면 3초 뒤 로그인 화면으로 이동한다. 기다리는 동안 진행 막대·3단계·경과 시간과 곧 열릴 화면, 체험 계정을 보여 준다. 체험 계정을 누르면 자동 이동을 멈추고 "바로 이동"을 기다린다. 60초가 넘으면 "평소보다 오래 걸리고 있어요" 상태로 바꾸고 새 탭 직접 열기·다시 확인하기를 제공한다. "기다리지 않고 바로 열기"도 항상 있다.

- 파일: `batteryflow-live.html`·`batteryflow-live.css`·`batteryflow-live.js`. 서비스 주소는 HTML의 `data-target`, 느림 판정 시간은 `data-slow-after`(초)에서 바꾼다.
- 확인 방식: `fetch(..., {mode:'no-cors'})`는 응답 내용을 읽지 않고, 서버가 응답을 보내면 완료되는 것만 이용한다. 서비스 쪽 CORS 설정은 필요 없다. 요청 하나가 45초를 넘거나 네트워크 오류가 나면 2초 뒤 다시 요청한다.
- 안내 문구의 "20–30초"는 실측 전 임시 값이다. 실제 콜드 스타트 시간을 재서 맞춘다.
- 미리 깨우기: BatteryFlow 상세 페이지가 로드되면 화면에 보이지 않는 요청을 한 번 보내 서버를 미리 깨운다. "라이브 서비스 열기" 링크의 `data-prewarm`에 주소를 넣으면 `site.js`가 처리하며, 같은 탭에서 3분 안에 다시 열거나 데이터 절약 모드면 보내지 않는다. 상태 문구는 표시하지 않는다(사용자 결정).
- `Claude outputs/`(검토용 시안)는 `.gitignore`로 배포에서 제외한다.
