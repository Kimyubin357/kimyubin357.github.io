## 인터뷰의 확인 범위

버튼 클릭 후 start=35&end=59 YouTube iframe 연결을 요청함을 확인했다. IAB에서 iframe은 about:blank 상태로 로드되지 않아 **실제 재생과 59초 종료는 확인하지 못했다**. 직접 임베드 URL도 플레이어 구성 오류를 표시했다. 네트워크/브라우저/YouTube 중 원인은 확정하지 않는다.

8초 내 로드되지 않으면 빈 화면 대신 35초 원본 링크로 전환한다. 타임아웃 뒤 해당 링크가 표시되고 iframe이 제거되는 실제 동작을 확인했다. 일반 브라우저에서 영상이 로드되면 내장 재생을 제공한다. 원본 YouTube 링크는 처음부터 항상 표시한다. 실제 영상 재생을 완료 검증했다고 표현하지 않는다.

## 시안 비교

내장 Image Gen로 5개 시안을 먼저 생성한 뒤 구현했다. concept-*.png와 실제 IAB getScreenshot 캡처 render-*.png / preview.png를 view_image로 직접 비교했다. 초기 full-page 캡처는 스크롤·뷰포트 조정 중 불완전하게 저장되어 삭제하고 정지 화면으로 대체했다.
