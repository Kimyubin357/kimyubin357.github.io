## 현재 버전의 수치 근거 확인

GitHub `Kimyubin357/Batteryflow-ML-Platform`의 커밋 `8753ffd187f8fc9b465755e670efca7b3ab09ba4`에 고정해 공개 자료를 받았다. 다른 작업 폴더에서 원본을 이동하지 않았다.

- 전체 비교 CSV: 9개 방법, 평가 1,289행·112개 부품·12개 목표일·외부 검증 3개 구간 확인. 원본 바이트를 `evidence/cv_metrics_pooled.csv`로 보존하고 상세 페이지에 연결했다.
- 저장 예측에서 MAE·RMSE·WAPE·예측 편향·R²를 재계산했다. LSTM·XGBoost는 CSV 문자열을 직접 float64로 읽으면 최대 약 3.53×10⁻⁷의 지표 차이가 있었으며, float32 표현을 복원하면 원본 지표와 일치했다. 사이트의 소수 첫째 자리 수치에는 영향이 없다.
- MA7 34.7, LSTM 35.2, 기존 계획 54.8 및 LSTM이 학습형 후보 중 최저 MAE라는 설명 확인.
- 목표일 단위 paired cluster bootstrap 20,000회·seed 42·linear quantile로 95% 구간 −13.59095%~59.22377%를 재현했다. 전체 개선율 36.70069%, 첫 구간 제외 시 −16.39950%와 구간별 결과도 일치했다.
- 저장 예측과 원래 검증 스크립트의 SHA-256이 기존 JSON의 해시와 일치했다. 기존 JSON 두 개는 GitHub 원본과 내용이 같고 LF/CRLF 줄바꿈만 다르다. 기존 파일과 2026-10-06 원검증 날짜는 유지했다.
- Copilot JSON의 수치 계산·보존된 상위 7개 정렬·Part 60/66 동률을 확인했다. 전체 107개 후보의 백엔드 실행과 원본 데이터 전처리는 재수행하지 않았다.
- 수치 재확인 날짜는 상세 하단에 2026.10.13으로 표시했다. 원본 자료 위치·커밋·해시·재계산 결과는 `evidence/source_comparison.json`, 해석과 범위는 `evidence/README.md`에 기록했다.
- 모델 재학습, 원격 DB 접근, Gemini 호출은 수행하지 않았다. 신뢰구간은 저장 예측의 사후 불확실성이며 날짜 간 자기상관과 모델 선택 편향을 보정하지 않는다.

### 실제 DOM·화면 검사

- 정상 메인 제목·본문·대표 카드 1개 표시, 기본 링크 중복 없음. 상세 이동 및 검증 근거 펼치기 통과. 오류 오버레이 없음.
- JavaScript 비활성화, `site.js` 로드 차단, `projects.js` 로드 차단, 빈 프로젝트 목록 각각에서 기본 HTML 링크 표시·상세 이동 통과. `site.js` 로드 차단 시 `js` 클래스 즉시 해제 확인.
- 대표 카드의 태그에 잘못된 값을 주입해 생성 오류를 재현했다. 기본 링크가 유지되고 나머지 초기화가 완료되는 것을 확인했다.
- 데스크톱 실제 대시보드 이미지 로드와 모바일 카드 표시·가로 경계 확인. 정상 화면의 사이트 콘솔 오류·경고와 미처리 예외 없음. 실패 주입 시험의 요청 차단 오류 및 의도한 카드 생성 경고는 예상된 결과다.

### YouTube API 모의 검사

네트워크/API와 영상용 IntersectionObserver를 대체하고 가짜 타이머로 지연을 제어했다. 실제 동영상 재생 성능을 검증한 결과와 구분한다.

- 30% 노출 시 API 요청 없음, 60% 이상 노출 시 중복 생성 없음, `autoplay: 0`, 준비 전 재생 호출 없음, 준비 후 음소거 재생 및 화면 이탈 시 정지. 정확히 45%에서도 재생 확인.
- API 로딩 중 화면 이탈 → 준비 완료 시 재생 없음 → 재노출 시 재생.
- API 로딩 중 및 플레이어 생성 후 준비 전 클릭 → 요청 보관 → 준비 후 35초부터 소리와 함께 재생. 준비 전 플레이어 메서드 호출 없음.
- 모션 감소 설정에서 자동 로딩 없음. 직접 클릭하면 45% 미만에서도 재생. 소리 버튼은 음소거 해제·처음부터 재생·버튼 숨김.
- 10초 타임아웃 뒤 API 응답이 와도 플레이어 생성 없음. 이미 생성된 플레이어의 늦은 ready/state/error 이벤트도 링크를 덮어쓰지 않음.
- 재생 중 플레이어 오류 시 반복 타이머 정리. 자동 모드는 구간 끝에서 반복하고, 직접 클릭 재생은 시작 위치로 돌아가 정지.

### 실제 YouTube 재생 검사

- 실제 플레이어의 PLAYING 상태와 재생 시간 36.02초까지의 증가·음소거 상태 확인.
- 메인 상단으로 이동 후 실제 PAUSED 상태, 영상 재노출 후 재생 재개 확인.
- 실제 소리 버튼 클릭 후 음소거 해제 및 재생 확인. 59초 부근에서 35초로 돌아가 PAUSED 상태가 되는 수동 구간 종료 확인.
- YouTube `www-widgetapi.js`에서 origin 관련 postMessage 경고, Chrome의 Windows WebGPU powerPreference 경고가 발생했다. 사이트 소스의 미처리 예외는 없었고 실제 재생·정지 검사에 영향은 없었다.

총 18개 시나리오(실제 DOM 7개, 영상 모의 10개, 실제 재생 시작 1개) 통과. 추가 실제 재생 진행·이탈 정지·소리 버튼·구간 종료 검사도 통과. 이번에는 실제 모바일 YouTube 재생, 배포 환경, 다른 브라우저, 실제 자동 반복을 연속 관찰하지 않았다. 기존 히어로·마키 폭 문제와 폰트 용량은 이번 수정 범위 밖이다.
