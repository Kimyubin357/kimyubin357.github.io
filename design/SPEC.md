# 개인 포트폴리오 구현 기준 · v0.1.0

버전 `0.1.0` · 현재 구현 기준일 2026-10-13. 초기 디자인 기준은 [SPEC-2026-10-07.md](SPEC-2026-10-07.md)에 보존한다. 초기 시안 이미지와 과거 렌더는 현재 디자인의 승인 기준으로 사용하지 않는다. 검증 결과는 [QA.md](QA.md), 수치 출처는 [근거 자료 안내](../evidence/README.md)를 참고한다.

## 구조와 실행

- 독립 정적 사이트: HTML·CSS·일반 JavaScript. Python 표준 라이브러리는 loopback 미리보기 서버에만 사용한다.
- 메인 `index.html`, BatteryFlow 상세 `batteryflow.html`, 새 상세용 `project-template.html`. 프로젝트 목록은 `projects.js`, 공통 동작은 `site.js`, 디자인은 `styles.css`다.
- 실행은 `start.cmd` 또는 `python serve.py`. 기본 주소 `http://127.0.0.1:8765/`. BatteryFlow 서비스의 가상환경·API·DB는 실행 의존성이 아니다.
- 대표 프로젝트는 order 순 최대 3개. 대표 외 항목이 있으면 전체 목록을 표시하고 분야가 둘 이상일 때 필터를 제공한다.
- 버전은 루트 `VERSION`이 기준이다. 세 HTML의 CSS·JS 캐시 버전과 README·이 문서·QA의 현재 버전을 함께 맞춘다.

## 콘텐츠와 자산

- 김유빈 / 데이터 분석·머신러닝 엔지니어 / 제조업 관심. 현재 프로젝트는 BatteryFlow AI 한 개다.
- 메인 순서: 소개 표지 → 기술 마키 → SBS 인터뷰 → 대표 프로젝트 → 필요 시 전체 프로젝트 → 소개·기술 → 학력·자격 → 연락.
- 표지 문구: “분석을, / 사용 가능한 / 서비스로 연결합니다.”, “데이터 분석 · 머신러닝 엔지니어 김유빈”, 제조 데이터 분석·모델 비교·API·대시보드 구현 소개.
- 메뉴는 프로젝트·인터뷰·소개·연락이며 420px 이하에서는 인터뷰 메뉴를 숨긴다. 영상 자체는 유지한다.
- 인적 정보 확인 기준일 2026-10-07. 부트캠프 참여 중, 사용자 제공 학력·자격증 내용과 로고 4개를 사용한다. 집 주소·전화·생년월일·자격번호는 포함하지 않는다.
- 프로필은 원본을 보존하고 480/960px JPEG 파생본을 srcset으로 제공한다. 실제 서비스 캡처와 SUIT Variable 로컬 폰트를 사용한다. 생성 시안 이미지를 사이트 UI로 넣지 않는다.
- 공개 GitHub·이메일·BatteryFlow 라이브 링크를 제공한다. 체험 계정은 공개용 데이터이며 보기/숨김·복사 버튼을 제공한다. 운영용 비밀 키는 저장하지 않는다.

- 현재 색상: 배경 #FFFFFF, 본문 #111A2E, 강조 #2457D6, 보조 #5A6579, 구분선 #E3E7EE, 연락·영상 배경 #0A0F1D.
- 컨테이너 최대폭 1280px. 기본 좌우 여백 32px, 820px 이하 20px. 헤더 높이 76px, 820px 이하 64px.
- SUIT Variable 100–900, 기본 본문 18px, 820px 이하 17px. 표지 제목은 clamp(44px, 6.3vw, 92px).
- 카드·그라데이션·그림자·둥근 버튼·스크롤 등장·패럴랙스·진행바·기술 마키를 사용한다. 초기 시안의 장식·모션 금지 원칙은 적용하지 않는다.
- 1100px 이하 대표 카드는 1열, 학력·자격은 2열. 820px 이하 표지·소개·학력·자격은 1열이며 대표 카드의 sticky 효과를 해제한다. 표는 자체 가로 스크롤을 허용한다.
- 키보드 포커스·본문 바로가기·이미지 대체텍스트를 제공한다. 모션 감소 설정에서는 애니메이션·자동 영상 재생을 제한한다. 인쇄용 최소 스타일을 제공한다.

## 실패 대응과 영상

- 대표 프로젝트 영역에 일반 HTML 상세 링크를 둔다. 대표 데이터가 있고 카드 생성이 성공한 경우만 카드로 교체한다. 데이터 없음·스크립트 실패·카드 생성 오류에서 링크를 유지한다.
- 세 HTML은 site.js 로드 실패 시 즉시, 준비 완료 표시가 없으면 head 실행 후 3초에 js 클래스를 해제한다. 정상 초기화에서는 기존 등장 효과를 유지한다.
- SBS 영상 ID RI5JTzQbqe4, 재생 구간 35–59초. YouTube 플레이어의 autoplay는 0이며 준비 완료 이후 실제 45% 이상 노출일 때 음소거 재생·반복한다. 화면을 벗어나면 일시정지한다.
- 직접 클릭은 45% 조건 없이 소리와 함께 35초부터 재생하고 구간 끝에서 시작 위치로 돌아가 정지한다. 준비 전 클릭은 보관한다. 사용자 재생이 일시정지된 뒤에는 재노출만으로 자동 재개하지 않는다.
- 중복 플레이어 생성을 막는다. HTTP origin 없음·오류·10초 타임아웃 시 원본 링크로 전환하며, 이후 늦은 API 응답·이벤트는 무시하고 반복 타이머를 정리한다.

## 수치와 검증 기준

- 수치 원본: 공개 BatteryFlow 저장소 커밋 8753ffd187f8fc9b465755e670efca7b3ab09ba4의 audited_v2/source_total. 원본 CSV와 원검증 JSON, 이번 재계산 출처·해시 기록을 evidence에 보존한다.
- 비교는 9가지 방법, CV 1,289행·112개 부품·12개 목표일이다. MA7 MAE 34.7, LSTM 35.2, 기존 D+3 계획 54.8. LSTM은 학습형 후보 중 최저 MAE다.
- 전체 개선율 36.7%와 0을 포함하는 95% 구간 −13.6%~59.2%, 첫 구간 제외 시 16.4% 악화를 함께 표시한다. 계획 검토 기준선이라는 활용 범위를 유지한다.
- 원검증일 2026-10-06, 내용 기준일 2026-10-07, 원본 대조·재계산일 2026-10-13을 구분한다. 학습 재수행이나 독립 시험 결과로 표현하지 않는다.
- 메인→상세→근거 열람, 영상 로딩·클릭·이탈·타임아웃, JS 실패 링크를 확인한다. 버전 일치·내부 파일과 앵커·JS/Python 구문을 검사하며 실제 브라우저와 모의 API 검증을 구분한다.
- 기존 데스크톱 히어로·마키 문서 폭 문제, 폰트 미축소, 배포 환경과 실제 모바일 영상 미검증은 QA에 남긴다.
